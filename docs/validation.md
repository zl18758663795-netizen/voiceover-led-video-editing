# 0.1.0 验证记录

日期：2026-10-21（Asia/Shanghai）。

## 独立场景试用

首次整理文件前，独立代理对两组输入给出了剪辑决策：82秒已有配音的画面剪辑，以及1.06倍整片提速。基线已经能正确处理这些情况，本记录不宣称本次 Skill 带来了可量化提升。整理的依据还包括实际制作中出现过的配音范围误判、字幕叠加、时间线不同步和验收表述问题。

完成技能后，另一位未读取上述基线答复的独立代理读取本 Skill，并处理三组变体：

| 场景 | 观察结果 |
|---|---|
| 90秒旁白、末条字幕89.6秒、横屏参考、仅52秒实拍 | 保留配音与字幕，采用参考画幅，补足有用画面，区分完整审核片与部分预览 |
| 100秒整片1.08倍、原0.8倍镜头、字幕54–60秒、多个音轨与部分烧录字幕 | 正确计算92.593秒、字幕50–55.556秒、镜头0.864倍；同步所有轨道，并按区间处理重复字幕 |
| WAV转AAC哈希变化、字幕提前0.4秒结束、缺少nb_frames，仅解码与首尾抽帧 | 未据此重配音或拉长字幕；区分技术信息与观感检查，保留待完整视听的审核状态 |

试用者未发现阻止复用的实质缺陷。这些是基于给定媒体元数据的行为试用，没有实际操作用户工程，不能替代真实成片验收。

## 基础命令验证

在隔离临时目录生成2秒、180×320、30fps、H.264视频与AAC测试音频，实际执行了参考文件中的四条检查命令：

- ffprobe媒体信息读取；
- FFmpeg完整解码；
- 首帧提取；
- 倒数1秒处取帧。

四条命令均退出成功，测得时长2.000000秒，具有视频和音频，两张PNG均真实生成。测试只说明这些命令在本机可运行，未评价任何真实配音的主观听感。

## 文件包检查

技能创建工具的 `quick_validate.py` 返回 `Skill is valid!`；UI元数据和两份MIT许可证一致性检查通过。13处本地文件/章节链接全部有效。公开文件中未发现作者机器绝对目录、所检查的凭据格式或私人媒体。

分发包包含 `SHA256SUMS`，覆盖除清单自身以外的全部交付文件。打包后分别检查ZIP的CRC、文件覆盖范围与每个清单条目的SHA-256；压缩包整体哈希在交付时另行记录。
