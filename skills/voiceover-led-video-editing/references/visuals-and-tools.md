# 画面与工具

## 画面选择

每个画面回答当前旁白中的一个问题。先确定它是证据、背景、机制解释还是转场，再选素材。

- 真实事件、人物发言、操作与结果：优先真实素材，记录来源、时间和使用范围。历史或背景镜头需要清楚区分，不能用旧发布会暗示人物正在谈当前事件。
- 数字、流程、对比与因果关系：使用清楚的图形、标注或解释动画；数值与时间口径必须能回到来源。相邻剪接不构成事件因果证据。
- 已有截图与图表：复用并聚焦有用部分，保留必要分母、图例和上下文。横竖屏转换逐镜头检查主体、坐标轴与字幕，不批量硬裁。
- 素材不足：继续检索已有授权素材，安排有用的图解或有目的的局部复看。静帧推进适合真实静态信息，动图循环、末帧冻结和慢放应有明确用途。有缺口的预览需标明缺口；不要把占位包装成完整审核片。

节奏随信息与真实语音变化。约6–8秒可作为检查是否有新信息的提示，不是机械切镜周期；重要证据需要足够阅读时间。用户已有参考风格优先。

## 可选财经解释风格

仅在财经解释题材且符合用户需求时采用：

- 英文主内容、中文审核参考，冷静说明市场机制，区分事实、市场反应与推断。
- 首帧与首句就给出对象、冲突或结果；不擅自在已锁定的口播前增加 Logo、封面停留或静音。
- 实拍混剪与解释图形并用，必要时注明历史资料/示意，避免用“现场感”强化未证实结论。
- 选择2.5D纸卡风格时使用前中后层、真实遮挡、软阴影、差速视差与克制镜头运动；不能仅给平面图片套推拉就认定达标。
- 字幕安全区域按平台、画幅和主体确定；不要把固定30%空白套用到所有实拍画面。

## 选择已有工具

先发现当前环境已经安装、可访问且适合任务的能力，读取该工具本地说明再调用。下面是职责边界，不是对某个版本的兼容保证。

| 可用能力 | 合适的任务 | 需要额外确认的结果 |
|---|---|---|
| FFmpeg / ffprobe | 测量、裁剪、封装、确定性合成、变速与技术检查 | 实际时长、音轨、解码结果、字幕像素与声音 |
| JianYing / 其他剪辑软件接口 | 用户需要可编辑多轨工程、字幕和关键帧 | 工程能打开、轨道正确、导出 MP4 可播放 |
| HTML / Remotion / Web 图形渲染 | 已确定时间线的机制图解、图形叠加 | 浏览器预览与实际导出分别检查，输出不含审核 UI |
| 已安装的口播清理工具 | 已授权删除口误、重复、停顿的源视频 | 删除范围、剪后语音与字幕，遵循用户实际授权 |

### 可编辑工程

克隆或备份现有工程，再试改动；先检查 API 是否真实存在，不照抄旧版本方法名。不要对用户原工程直接执行带覆盖/重置语义的初始化。保存成功只证明工程保存了，仍要检查视频、音频、字幕、变速与关键帧，再检查实际导出。

项目脚本放在用户工程内。用参数、工具环境变量或当前环境发现定位能力；不要把作者机器的安装目录、声音目录或草稿路径写死进公开 Skill。遇到封装/加密草稿格式时，优先使用受支持的读取或编辑方式，不能按普通 JSON 猜测重写。

### 预览与外部服务

本地浏览器预览确认 HTTP Range/拖动定位可用，不能把网页能打开视为视频可播。渲染页仅包含成片内容，审核按钮、时间线、调试文字独立。

优先复用已有媒体、字幕与转录缓存。新增云端转写或生成时，确认现有授权是否覆盖费用与素材上传；公开托管私有音频不是默认的本地剪辑步骤。没有真实素材时，先说明可完成部分与缺口，按授权选择补素材方式。
