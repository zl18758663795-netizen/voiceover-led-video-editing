# 工作示例

数值用于演示剪辑判断，不是附带的真实工程，也不表示本 Skill 已经渲染过这些作品。

## 已有82秒配音的画面剪辑

输入：已确认旁白82.0秒；32条 SRT，末条结束于81.7秒；旧文稿标题“60秒”；参考为16:9真实财经素材；已有八段各5秒的动图视频。用户只要求画面剪辑，保留音频、SRT及时间。

做法：以82.0秒主时间线编排，SRT原件保持不变。参考优先于工具默认3:4；如需具体分辨率，结合源素材选择并说明，不能只因工具默认就裁成竖版。40秒动图不是整片覆盖，优先从已有合法来源补充实拍、图表和有意义的局部复看；不能为凑足82秒把全部视频硬拉慢或自动提交付费生成。

用户已授权本地剪辑，直接完成可播放的审核片。确实缺素材时保留清楚标注的部分预览与缺口清单，询问影响补齐的必要信息，不把有占位的片子称为完整审核片。末条字幕结束后的0.3秒可能是正常收尾，不自动延长字幕或剪掉声音。

## 整片1.06倍速返修

输入：原片99.52秒；某 cue 为79.5–83.25秒；一个镜头使用源10–19秒、速度0.90倍；用户要求整片1.06倍速并保留原版。

逐轨重算时：

```text
预计总时长 = 99.52 / 1.06 = 93.886792… 秒
cue = 75.000000… – 78.537735… 秒
镜头源范围 = 10–19秒，不变
镜头新速度 = 0.90 × 1.06 = 0.954倍
镜头新显示时长 = 9 / 0.954 = 9.433962… 秒
```

音乐、现场声、音效、字幕和关键帧都按同一主时间映射；嵌套整片变速时不再修改子片段速度。量化到具体帧率并导出后实测，检查声音音调、衔接和片尾。

原片有烧录字幕时，先决定保留它或换用干净源，避免再叠一份字幕。编码成功、哈希匹配和首尾帧都正常，只能报告相应技术检查通过；完成检查前交付为审核片，并列出尚未进行的完整播放或听音。

## 局部换镜头

用户仅要求替换22–28秒的背景镜头，旁白、字幕、其他画面保持。新素材只有4.8秒。

先复制工程，锁定22–28秒外的主时间线与全部声音/字幕。为6秒的画面槽位补足有意义的内容：选更长的合适素材，或采用合理的双镜头/静态解释组合。只有确有叙事用途时才考虑该片段慢放或定帧；不得为适应4.8秒素材压缩旁白、缩短整片或挤动后续字幕。检查22秒与28秒两端的转场及字幕，再导出新版本。
